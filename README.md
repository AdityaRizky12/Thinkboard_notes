# 🧠 ThinkBoard Notes

ThinkBoard Notes is a simple full-stack web application that allows users to create, manage, and organize notes easily.
This project was built as a practice project to improve my skills in modern web development using React and Node.js.

---

## 🚀 Features

* Create new notes
* Edit existing notes
* Delete notes
* Simple and clean user interface
* Fast note management system

---

## 🛠 Tech Stack

**Frontend**

* React
* Vite
* Tailwind CSS

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

---

## 🌐 Live Demo

This project is not deployed yet.
You can run it locally by following the installation steps below.

---

## ⚙️ Installation

Clone this repository

```bash
git clone https://github.com/AdityaRizky12/Thinkboard_notes.git
```

Go to the project folder

```bash
cd Thinkboard_notes
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
